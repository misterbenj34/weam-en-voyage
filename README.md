# Weam en voyage

Blog de voyage, publié avec GitHub Pages.

Site : https://misterbenj34.github.io/weam-en-voyage/

## Structure

- `index.html` : page d'accueil avec la liste des articles
- `articles/` : un fichier HTML par article
- `style.css` : mise en forme commune
- `.nojekyll` : désactive Jekyll, le site est du HTML statique pur

## Ajouter un article

1. Créer `articles/nom-de-l-article.html` en copiant `articles/bonjour.html`.
2. Ajouter un lien dans la liste de `index.html`.
3. Commit et push sur `main` : GitHub Pages met le site à jour automatiquement.
